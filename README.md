# AIR44 — выпуски / Releases

**AIR44** — студия эфиров от **CODE44**: сцены, графика, запись и трансляция для Windows.

Здесь лежат готовые установщики и обновления. Исходный код — в закрытом репозитории CODE44.

## Установить

Скачайте `AIR44-Setup-<версия>.exe` из [последнего выпуска](https://github.com/Code44Team/AIR44-Releases/releases/latest) и запустите.

## Обновления

AIR44 сама проверяет этот репозиторий: через минуту после запуска и потом каждые 3 часа.
Новую версию программа скачивает в фоне и ставит, когда вы её закрываете. При следующем запуске откроется уже новая версия.

Каждый выпуск содержит `latest.json`, подписанный ключом CODE44 (Ed25519), и установщик с контрольной суммой SHA-256.
Программа ставит только то, что прошло обе проверки, поэтому подменить обновление через GitHub нельзя.

---

**AIR44** is a live production studio by **CODE44** for Windows. This repository hosts installers and updates; the app checks it automatically, downloads new versions in the background and installs them when you close it. Every release is signed (Ed25519) and checksummed (SHA-256).
